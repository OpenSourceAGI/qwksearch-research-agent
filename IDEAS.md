## Near-term features

- **🧩 Extension Setup** — Build the browser extension around a streamlined download-to-reasoning workflow, so users can capture pages, open related research, and move from browsing into an organized AI-assisted workspace with minimal friction.
- **💡 Related Sidebar Suggestions** — Add keyword-based recommendations to the sidebar that detect the current page’s main topics and suggest related documents, searches, tabs, or saved outlines for deeper exploration.
- **🗂️ Open-Tab Chat Context** — Let users chat with the AI using their currently open browser tabs as selectable context, allowing the assistant to compare sources, answer questions, and synthesize information without requiring manual copying.
- **📊 Model Vals Scores** — Display Vals performance data for every supported model, including a clear metrics panel with the Vals Index, average latency, and estimated cost per test; for example, a Kimi K2.5 page could show a 51.70% Vals Index, 807.18-second latency, and $0.29 per test.
- **🌳 Reusable Outline Tree** — Implement the outline tree using Fumadocs-inspired page-tree and sidebar patterns, so nested documents, topic groups, and navigation roots remain consistent, expandable, and easy to scan.
- **🔎 Outline Filtering** — Add a fast filter field above the outline tree so users can narrow large documentation or research hierarchies by title, keyword, tag, or content match.
- **📝 Global Find and Replace** — Provide find-and-replace across every document in a workspace, with previews and confirmation controls so broad edits can be reviewed before they update multiple notes or pages.
- **🎙️ Instant Voice Conversations** — Offer a preference that automatically starts a voice conversation on a user’s first visit, while also exposing a persistent button that can launch voice chat from anywhere in the product.
- **🏆 App Directory Inspiration** — Use OpenRouter’s app and agent directory as product inspiration for public app discovery, attribution, category browsing, usage visibility, and rankings.[^1](https://openrouter.ai/apps)
- **🔍 Reasoning Zoom Preference** — Set the reasoning or chain-of-thought-style viewer to open at 125% zoom by default, making dense AI output easier to read while preserving an adjustable zoom control.
- **✍️ Typo Assistance** — Add common typo detection and correction throughout searches, titles, commands, and prompts, while preserving intentional technical terms, URLs, model identifiers, and code-like text.
- **☁️ Moltworker Research** — Evaluate Cloudflare’s Moltworker project as a reference for running an OpenClaw-style personal AI agent in Cloudflare Sandbox containers, including browser automation, persistent R2-backed state, AI Gateway routing, and explicit device-pairing security.[^2](https://github.com/cloudflare/moltworker)

## Long-term features

- **🧠 Extension Tab Capture** — Use a CRX browser extension to access authorized open tabs, extract page content and metadata, and turn those tabs into structured research context for search, chat, summaries, and topic outlines.
- **📰 AI News Monitor** — Create a configurable AI agent that watches user-defined topics, continuously gathers relevant updates, deduplicates coverage, and produces a personalized news feed with concise explanations and source links.
- **🧭 Unified Main Navigation** — Organize the primary navigation around Tabs, AI Chat, Web Search, Favorites, and History so users can switch between browsing, researching, asking questions, and returning to previous work without losing context.
- **⚡ Cached Topic Queries** — Run queries against cached pages already attached to a topic outline before expanding to the live web, making repeated research faster, cheaper, and more grounded in the user’s saved source collection.
- **🎬 Research Video Queue** — Enable research agents to identify and queue the next relevant video automatically, so users can move through lectures, explainers, demos, and interviews as a coherent learning sequence.
- **➡️ Follow-up Suggestions** — Generate useful next questions after searches, chats, and page reads, helping users explore missing context, compare alternatives, challenge assumptions, or continue an unfinished research path.
- **📌 Sidebar Search Results** — Show web and internal search results directly in the browser sidebar, letting users inspect and open relevant sources without replacing the page they are currently reading.
- **🗂️ Persistent Tab Context** — Support open tabs as reusable AI context across multiple interactions, with controls to include, exclude, pin, group, and summarize sources before each request.
- **🚀 SSR Common Answers** — Preload and server-render result pages for common questions so high-frequency searches feel instant, remain crawlable, and have useful content available before client-side AI interactions load.
- **🌐 Smart Direct Navigation** — Detect when autocomplete strongly matches a domain or known destination, such as `red.com`, and navigate there immediately instead of treating the input as a conventional search query.
- **🤝 Sharing and Social Actions** — Add a share flow that can generate a link, compose an email to selected friends, and provide social-sharing actions for pages, topic outlines, chats, and research collections.
- **➡️ Next-Page Recommendations** — Suggest the most useful next page from the sidebar while a user reads, using the current source, saved topic structure, open tabs, and research history to make the recommendation relevant.
- **🔮 Topic Completion Prediction** — For each topic, use a model to predict likely next words, subtopics, related entities, and high-value research directions that can accelerate outlining and query formulation.
- **🔍 Sidebar Topic Auto-Search** — Automatically search for the active topic from the sidebar when appropriate, while providing visible controls so users can pause, refine, or redirect the search before unnecessary requests run.
- **💬 Contextual AI Tips** — Prioritize sidebar space for AI-generated guidance about the page currently being viewed, such as definitions, key claims, source quality notes, action items, related questions, and contradictions with saved materials.
- **🕸️ Question Connection Graph** — Cache user questions and their source-backed answers, then use semantic relationships to build connections among related questions, topic outlines, documents, and recurring research themes.
- **⬇️ Browser Controls and Downloads** — Add a Downloads tab alongside browser-style controls for Back, Refresh, Undo Close Tab, and New Tab, creating a familiar workspace for users who want research and navigation in one interface.
- **🏠 Default Search Integration** — Support optional default-search, homepage, and startup-page integration through Chrome’s `chrome_settings_overrides`, while designing the extension as a clearly scoped feature because Chrome applies verification and single-purpose-policy constraints to those overrides.[^3](https://developer.chrome.com/docs/extensions/reference/manifest/chrome-settings-override)
- **🤖 Dataset Research Agents** — Build specialized agents that can browse the web and work with permitted datasets, including professional-network-style sources such as LinkedIn where access, permissions, terms, rate limits, and privacy requirements are respected.
- **⌨️ AI-Enhanced Ctrl+F** — Generate keyphrase and semantic completions for in-page Ctrl+F search, so a user looking for “pricing” can also find passages about costs, plans, subscriptions, rates, or fees.
- **📄 Markdown File Tree** — Create a Markdown and file-tree view inspired by modern document editors, combining readable source content with collapsible navigation, rich Markdown support, task lists, links, code blocks, and structured document organization.[^4](https://ld246.com/guide/markdown)
- **🌲 Multi-Root Documentation** — Reuse Fumadocs-style multi-tree and root-toggle concepts to let users switch among separate documentation spaces, repositories, projects, or research collections without mixing their hierarchies.
- **📣 Launch Distribution** — Plan a coordinated release across Hacker News, YouTube, and Product Hunt, with tailored launch material such as a technical write-up, product demo, onboarding flow, screenshots, and early-user feedback channel.
- **🧑‍💻 Agent Registry Reference** — Use the 21st.dev agent registry as a reference for discoverable agent templates, categorized capabilities, copyable configurations, and quick deployment patterns for coding, research, monitoring, and workflow agents.[^5](https://21st.dev/community/agents)
- **⚠️ Warning Source Navigation** — Add a dropdown action that inserts an “Ask about this” or “Show source” reference into the active tab, allowing users to jump directly to the location where a warning, annotation, or issue was originally created.
