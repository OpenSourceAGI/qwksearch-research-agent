# Get started

LeoTabs has two main views: the **library** for saved work, and the **switcher** for jumping between open pages. You can use both without an account or AI connection.

## Install LeoTabs

1. Open [LeoTabs in the Chrome Web Store](https://chromewebstore.google.com/detail/leotabs/heolckkdeandgagkiefggcneodniojhb).
2. Choose **Add to Chrome**, then **Add extension**. In Edge, allow extensions from other stores if prompted.
3. Pin LeoTabs from the browser's extensions menu so the lion is easy to reach.

On first install, choose System, Dark or Light in the welcome step, then follow the guide to saving, organizing and switching tabs. Six short recordings demonstrate the actions; use the video controls to pause or view them full screen. Import saved tabs from the final step. Use **Skip** or Escape at any point. Reopen it through **Settings → Quick start** or **Help → Quick start**. The guide appears automatically only once; updates and browser restarts do not reopen it.

LeoTabs requires Chrome 123 or newer, or a compatible Chromium browser. Browser policies can restrict installation and shortcuts. It is not a Firefox or Safari extension.

## Save your first collection

1. Open a few ordinary web pages.
2. Click the lion or press **Alt+Shift+Q** to open the library.
3. Choose **Save tabs**, the tray icon beside **Open tabs**.
4. Leave **and close them** unchecked to keep the tabs open, or check it to put them away. The button changes from **Save tabs** to **Stash tabs** when closing is selected.
5. Choose that button. LeoTabs creates a new collection; rename it and add a note describing where you stopped.

The other option, **and switch to new collection**, makes the new collection current without reopening your tabs. It is available when all unpinned tabs in the current window are selected, and cannot be combined with closing them.

To save into an existing collection, drag tabs from **Open tabs** into it. This keeps the original browser tabs open.

Your saved collection remains after you close its browser tabs. Core website grouping and saving do not need AI. If you later configure AI, new saves can be named automatically; read [AI setup](ai.md) first.

## Understand the layout

The left sidebar shows open tabs and recent pages. The main area shows collections in the selected space. A space is a section of your library; a collection is a saved set of links. The currently active collection can follow the open tabs in its window when Auto-update is on.

Open **Settings** near the top-right for appearance, connections, export/import and privacy controls. Use **Alt+Q** for the visual switcher or **Alt+Shift+K** for search only.

## Keep your work safe

Download a backup before uninstalling, changing browser profiles or replacing an unpacked installation with a store installation. Different installations can have separate local data. Updating the files of the same unpacked installation and pressing Reload is different from removing it.
