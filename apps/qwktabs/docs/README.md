# LeoTabs user guide

LeoTabs helps you find open pages, save browsing work into collections and return to it later. Start with the [first-use walkthrough](getting-started.md), or choose a guide below.

Connecting a service? Go straight to [AI setup](ai.md) or [Notion setup](notion.md).

## Everyday browsing

| Guide | What you will learn |

| [Get started](getting-started.md) | Install, open the library and save your first collection |
| [Your library](library.md) | Spaces, collections, notes, colours, pinning and reordering |
| [Save, open and switch](saving-switching.md) | Choose the right action and control automatic updates |
| [Search and shortcuts](search-shortcuts.md) | Switcher, search, keyboard navigation and scopes |
| [Groups and selection](groups-selection.md) | Group, sort, drag, copy and act on multiple tabs |
| [Backup, import and export](import-export.md) | Keep portable copies and move between installations |
| [Undo and recovery](recovery.md) | Recover saved work and understand what cannot be restored |
