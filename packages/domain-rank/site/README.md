# domain-rank-site

Fumadocs site for `domain-rank` (docs + demo) as a Next.js app.

- Docs: `/docs`
- Demo: `/demo` (sample top-domain listings and search over bundled data)

## Dev

```bash
cd packages/domain-rank/site
bun install
bun run dev
```

## Build

```bash
bun run build
bun run start
```
