`write-language` is a small toolkit for asking a language model a question and getting back
clean, ready-to-render HTML. One function call picks the provider, fills in a pre-tuned prompt,
trims it to the model's context window, calls the model through the
[Vercel AI SDK](https://ai-sdk.dev), and converts the Markdown reply to syntax-highlighted HTML.

```ts
import { writeLanguageResponse } from 'write-language';

const { content, error } = await writeLanguageResponse({
  provider: 'groq',
  apiKey: process.env.GROQ_API_KEY,
  query: 'Explain quantum computing in simple terms',
});
```

## How a call works

<Steps>
<Step>

**Resolve the provider and model.** The `provider` name is lowercased and checked against the
registry. If you don't pass `model`, the provider's registered default is used.

</Step>
<Step>

**Build the prompt.** The `agent` template (default `question`) is loaded from
[`AGENT_PROMPTS`](/docs/agents), its `before` hook runs, and every `{placeholder}` is filled
from your options.

</Step>
<Step>

**Fit the context window.** The prompt is cut to the model's `contextLength` unless you set
`applyContextLimit: false`.

</Step>
<Step>

**Call the model.** `generateText` from the AI SDK runs with your `temperature`. Attachments
turn the call into a multimodal message.

</Step>
<Step>

**Format the reply.** The Markdown answer becomes HTML (or stays Markdown with `html: false`),
and the agent's `after` hook can pull structured data into `extract`.

</Step>
</Steps>
