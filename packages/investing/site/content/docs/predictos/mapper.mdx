  }}

## What it does

<Steps>
<Step>Validates the platform, the analysis and the market, and that `budgetUsd` is between **$1** and **$100**.</Step>
<Step>`NO TRADE` → throws `NoTradeError`. Catch it: it is a decision, not a failure.</Step>
<Step>Refuses closed markets and markets with `acceptingOrders: false`.</Step>
<Step>Finds the side's token: `BUY YES` picks the outcome named `Yes` or `Up`, `BUY NO` picks `No` or `Down`.</Step>
<Step>Rounds the current price to the tick size (default `0.01`) and buys `floor(budget / price)` shares.</Step>
<Step>Throws if that is fewer than **5 shares** (Polymarket's minimum), telling you the minimum budget at this price.</Step>
</Steps>

## Handling every outcome

```ts
import { runMapperAgent, NoTradeError, type AnalysisResult, type MarketData } from "investing/predictos";

function toOrder(analysis: AnalysisResult, market: MarketData, budgetUsd: number) {
  try {
    return { kind: "order" as const, ...runMapperAgent({ platform: "Polymarket", analysisResult: analysis, marketData: market, budgetUsd }) };
  } catch (e) {
    if (e instanceof NoTradeError) return { kind: "skip" as const, reason: e.message };
    const msg = (e as Error).message;
    if (msg.startsWith("Budget too small")) return { kind: "skip" as const, reason: msg };
    if (msg === "Market is closed" || msg === "Market is not accepting orders") return { kind: "skip" as const, reason: msg };
    throw e; // bad input: a bug upstream
  }
}
```

<Callout type="warn" title="The limits are deliberate">
  `$1 ≤ budget ≤ $100` and `size ≥ 5` are risk guards for autonomous runs. Size larger positions with your own
  logic and several orders, rather than by loosening the mapper.
</Callout>

Kalshi mapping is not implemented; `KalshiOrderParams` is declared for when it is.
