## What makes it different

<Highlights>
  <Highlight title="Open source">
    Read it, fork it, [run it yourself](/docs/self-hosting) on Cloudflare Workers or locally
  </Highlight>
  <Highlight title="Any model">
    Claude, GPT, Gemini, Grok, Llama, DeepSeek — or your own OpenAI-compatible endpoint
  </Highlight>
  <Highlight title="Full-text grounding">
    Answers cite text actually [extracted](/docs/reader) from each source, not search snippets
  </Highlight>
  <Highlight title="Real citations">
    APA metadata parsed from the page and validated against a 90k-name database
  </Highlight>
  <Highlight title="Research writing">
    [REASON](/docs/reason-editor) turns an answer into a structured, cited document
  </Highlight>
  <Highlight title="Everywhere you work">
    [Browser](/docs/browser-extension), [desktop](/docs/desktop-app), [VS Code](/docs/vscode-extension), and [MCP](/docs/mcp-server)
  </Highlight>
</Highlights>

See the [feature list](/docs/features) for detail, or the
[comparison](/docs/comparison) against Perplexity, ChatGPT, Claude, Gemini and
Grok.

## Try it

Nothing to install — [qwksearch.com](https://qwksearch.com) works signed-out.

To run it yourself:

```bash
bun x git0 vtempest/qwksearch-research-agent
cd qwksearch-research-agent
bun install
cd apps/qwksearch-web && cp .env.example .env
bun run dev
```

To call it from code:

```bash
bun i qwksearch-api-client
```

To use it from Claude Desktop or another MCP client, see the
[MCP server](/docs/mcp-server).

## For developers

The monorepo publishes ~20 standalone packages — the search aggregator, the
extractors, the multi-provider LLM toolkit, the chat UI and the editor are all
usable on their own. See [Packages](/docs/packages).
